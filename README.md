## 데이터 누락 점검과 처리

63개 이미지는 실제 0바이트였고, 학습 라벨 2,112개와 검증 라벨 40개가 제공 자료에서 확인되지 않았다. 라벨 미확보 2,152개 중 63개는 빈 이미지와 겹친다. 내용은 있으나 라벨이 없는 이미지는 2,089개다.

다른 폴더·파일명 표기 차이·동일 이미지까지 재검증했으나 정확하게 복구할 근거를 찾지 못했다. 정상 쌍과 보류 파일을 목록으로 분리하고, 원본을 보존했다. 누락 라벨을 정상 배경으로 간주하거나 빈 주석을 생성하지 않았다.

## 수행 범위와 다음 단계

1주차의 환경 확인·관찰·기준서 작성을 완료했다. 하드 네거티브는 제출 최소 3종을 충족하는 4종 후보이며 권장 목표 5종에는 미달한다. 모델 학습 및 성능 평가는 아직 수행하지 않았다.

검증 라벨이 없어 기존 분할 그대로의 다음 주 학습 준비는 미완료다. 누락 자료를 재확보하거나, 사용 가능한 학습 원본 그룹으로 새로운 검증 설계를 명시해야 한다.

PDF는 7쪽 전체 페이지 검수를 완료했다. Word는 편집용이며 렌더러 부재로 페이지 배치를 별도 검증하지 못했다.

### 학습 곡선에서 확인한 결과

검증 mask mAP50-95가 가장 높았던 에폭은 26이다. 해당 에폭의 mask mAP50은 **0.58719**, mask mAP50-95는 **0.20738**이었다. 이는 검증 곡선의 기록이며 테스트 성능이 아니다. `best.pt`는 라이브러리의 검증 fitness 기준으로 선택했다.

학습 segmentation loss는 첫 에폭 5.50664에서 마지막 에폭 1.69823으로 감소했다. 검증 지표는 에폭마다 변동했으며, 26에폭 이후 검증 fitness가 20에폭 동안 개선되지 않아 조기 종료됐다. 상세 곡선과 처리 과정은 보고서에 수록했다.

### 해석과 남은 작업

이번 실습은 원본 중심의 소규모 학습 파이프라인 확인이며, 기존 증강본을 모두 포함한 논문 실험의 동일 조건 재현은 아니다. 파일명 기반 원본 분리는 같은 시설·촬영 세션의 서로 다른 프레임까지 독립임을 보장하지 않는다.

GPU 학습과 가중치 확보, 학습 곡선 확인을 완료했다. 직접 폴리곤 주석 과제는 기존 라벨 검토와 구분해 미완료로 남겼다. 테스트 40장의 추론 평가와 클래스별 신뢰도 임계값 탐색은 아직 수행하지 않았으며 3주차 단계로 보존한다.

2주차 PDF는 6쪽 전체 페이지 검수를 완료했다. Word는 편집용이며 페이지 배치는 렌더러 부재로 별도 검증하지 못했다. 학습 가중치와 원본 데이터는 이번 보고서 업로드에 포함하지 않았다.
